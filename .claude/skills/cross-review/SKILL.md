# クラウドでの相互レビュー

この写しはクラウドのセッション向け。
ローカルでは `~/.claude/skills/cross-review/SKILL.md` が優先される。
ローカルでこれが読まれたなら、上流の checkout で `node tools/cross-review.sync-all.js --global-skill` を実行してホームの SKILL を配る。

## レビューの準備

レビューは常に同じベンダーの客観サブエージェントで回す。
実装者を報告し、改修が一区切りしたら次の3択を選択 UI で提示する。
UI が使えず対話可能なら、同じ順序の選択肢を本文で提示して返信を待つ。

1. 別ベンダーでレビュー
2. 同ベンダーでレビュー (推奨)
3. レビューしない

クラウドには別ベンダーの CLI が無いため、1を選んだ場合も同じベンダーの読み取り専用サブエージェントで代替した旨を記録する。
開発者の指定があれば提示を省き、自走中は指定か推奨の経路で進める。
誤字、コメント、文言調整、整形のみなどの軽微な変更では3を推奨し、省略理由を報告する。
レビューの前に feature ブランチと PR を用意する。
リモートが無いなど PR を作れない場合だけ、その理由を報告して省略する。
観点はプロジェクトの `.cross-review.md` を使う。

## 読み取り専用レビュー

本体はキャッシュの経路で git の shallow fetch により取得される。
取得に失敗したらネットワークの許可を確かめる。

1. `node tools/cross-review.js subagent` を実行し、stdout のレビュープロンプトを保存する。未コミット差分には `--uncommitted` を付ける。
2. プロンプトと前の往復の判断ファイルを、読み取り専用の客観サブエージェントに渡す。実装意図に引きずられない第三者として調査し、別のベンダーへ依頼を転送しないよう指示する。
3. 主セッションが指摘を裏取りして修正を適用する。指摘、対応、妥当性確認は毎回 PR コメントに残す。
4. 修正後は同じ経路で妥当性を確認する。前回レビュー SHA が自動で base になるので、2回目以降は通常 `--base` を付けない。

経路設定により subagent が拒否される場合は `--override-route "対象レビュアー CLI 不在"` のように理由を付ける。
PR には「対象レビュアー CLI を直接実行できないため（CLI 不在 / 接続不可）subagent 代替で確認した」と記録する。
`subagent` は通常、状態を1往復進める。
`--no-state` を使った場合など CLI 外で確認した往復だけ、`node tools/cross-review.js state --mark` で記録し、二重に数えない。
現在値は `node tools/cross-review.js state` で確認する。

## PR コメントと往復の上限

開始時のブランチから決まる `.cross-review/branch-<slug>-<hash>/round-<N>-triage.md` に、指摘の裏取り、対応、検証を書く。
`node tools/cross-review.js comment --round <N> --outcome <fixing|converged|halted>` で本文を生成し、`gh pr comment --body-file <生成本文>` で投稿する。
`--post <PR番号>` を付ければ生成本文を直接投稿できる。
修正を続けるなら fixing、妥当性確認で収束したら converged、判断待ちで打ち切るなら halted を記録する。
コメント本文を手で組み立てない。

1往復は実装または修正、レビュー、主セッションによる結果確認までとし、最大3往復とする。
提案は任意適用で、継続理由にしない。
3往復後に blocker が残る場合、または要修正が1ファイル内に収まらず既存テストで検証できない場合は中断する。
残存指摘、試した対応、収束しない理由の推測、選択肢をまとめて開発者に判断を求める。
要修正だけで1ファイル内に収まり既存テストで検証できる場合は、主セッションで対応し、根拠を PR コメントに残して収束としてよい。
同じ指摘が揺り戻す場合は3往復を待たず中断してよい。
自走中は判断待ちを最終報告に載せ、そのブランチのレビューを打ち切って独立した残りの作業へ進む。
3往復を超えて続ける場合は、PR コメントの冒頭に往復数と継続理由を書く。

詳しい運用は [上流の正本](https://github.com/ktysne/ai-cross-review/blob/main/docs/cross-review.md) を参照する。
